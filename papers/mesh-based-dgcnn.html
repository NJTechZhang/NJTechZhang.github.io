期刊论文 · 城市三维网格语义分割

Mesh-Based DGCNN：纹理三维城市场景的语义分割

Mesh-Based DGCNN: Semantic Segmentation of Textured 3-D Urban Scenes

  • 作者：Rongting Zhang, Guangyun Zhang*, Jihao Yin, Xiuping Jia, Ajmal Mian
  • 发表：IEEE Transactions on Geoscience and Remote Sensing, 2023, 61: 4402812
  • 类型：SCI 期刊论文（中科院一区 TOP）
  • DOI：10.1109/TGRS.2023.3266273

摘要

纹理三维网格是摄影测量与遥感领域的最终用户产品之一，但面向复杂城市场景、以纹理三维网格为表达形式的语义分割研究仍处于起步阶段。本文提出一种面向纹理三维网格语义分割的网格化动态图卷积神经网络（mesh-based DGCNN）。为表征每个网格面片，论文构造了复合输入特征向量，把面片固有特征——重心（CoG）的 XYZ 坐标、纹理值与法向量（NV）——拼接在一起；同时把纹理信息融合（TIF）模块嵌入所提网络，用于生成高分辨率纹理的高层语义特征，以服务于语义分割任务。把该方法应用于 SUM 网格数据集时取得了有竞争力的精度：总体精度（OA）93.3%、Kappa 系数（Kap）88.7%、平均精度（mP）79.6%、平均召回率（mR）83.0%、平均 F1 分数（mF1）80.7%、平均交并比（mIoU）69.6%。其中，OA、平均类精度（mAcc）、mIoU 与 mF1 相比当时的最先进方法分别提升 0.3%、12.4%、3.4% 和 6.9%。

研究背景与动机

随着激光雷达等传感器的普及，三维数据的获取已相当经济。三维数据通常以点云、网格、体素栅格、RGB-D 影像等形式表达，相比二维数据在空间表达上优势明显，因此三维模型生成、分类与语义分割研究十分活跃，其中语义分割要求最高。作为摄影测量与遥感的最终成果之一，三维网格既承载精细几何，又以每个面片嵌入的高分辨率纹理影像区别于带颜色点云，蕴含更丰富的场景信息。

然而，已有工作按输入表达方式大致可分为三条路线，各有短板。其一，把网格直接作为输入：谱方法用图拉普拉斯特征向量构造谱卷积，模型难以跨域自适应；空间方法（如 PicassoNet-II 的 facet2vertex、vertex2facet 卷积，基于细分的 SubdivNet）对网格结构要求较严。其二，把重心点云作为输入：以面片重心生成 CoGP 点云再套用点云网络，但早期方法只得到全局特征、忽略局部特征，基于 PointNet++ 的方法在纹理受阴影或遮挡噪声影响时性能急剧下降，两流图卷积网络 TSGCNet 虽能学习更具判别力的几何特征却不够稳健。其三，体素化：把网格转成规则栅格做三维卷积，内存与算力开销巨大，且会损失测地信息。总体而言，这些方法多面向规模小、结构简单的数据集，常用特征基本是纯几何特征，未能充分利用纹理三维网格独有的高分辨率纹理，这正是本文要填补的空白。

方法与主要创新

  • 面向面片的复合输入特征向量构造。论文把网格表示为“重心点云”（CoGP cloud）：每个面片由其重心点代表，并附带面片固有特征。重心坐标由三顶点坐标取平均得到，即 X_C = (X_v1 + X_v2 + X_v3)/3，Y_C、Z_C 同理，可从 ASCII 文件解析获得。纹理特征通过专门的采样方法获取：先解析 ASCII 文件建立面片与纹理图集的对应关系，再把三顶点投影到像素坐标确定三角形状影像块；在三条边上各均匀取 n 个点（本文 n = 9），每个顶点与对边上的 n 个点组合生成 n 条线段，这些线段的交点即采样点，每个面片共采集 3n² = 243 个采样点，再经插值得到各点的 RGB 值。面片法向量由面片边向量叉乘得到。上述特征堆叠为一维复合特征向量 (X_C, Y_C, Z_C, R₁, G₁, B₁, …, R_m, G_m, B_m, n_X, n_Y, n_Z)。与已有工作不同，本文直接使用原始 RGB 值而不用均值或中值 HSV，以保留纹理信息。
  • 纹理信息融合（TIF）模块。纹理影像的 RGB 值可能受噪声影响且存在冗余，而在极高维空间中距离对噪声极为敏感，相似特征之间的距离也可能被噪声放大。为此网络嵌入由三个多层感知机（MLP）串联构成的 TIF 模块，其输出维度依次为 256、128、64，用于为每个面片生成纹理的高层语义特征。模块输入是 729 维纹理信息（243 个采样点 × 3 通道），输出 64 维高层纹理特征；随后与 3 维 XYZ 坐标、3 维法向量拼接成新的 70 维复合特征向量，送入后续模块。除第一个 MLP 外，每个 MLP 都作用于前一个 MLP 的输出，各层使用带泄漏的 ReLU（LeakyReLU）激活。
  • 带动态邻居选择的 EdgeConv 主干。整体网络由三个 EdgeConv 模块构成。与传统图卷积网络不同，每个 EdgeConv 中每个 CoGP 的 k 个邻居是动态确定的而非固定邻居，边缘特征由共享 MLP 学习后再经最大池化聚合，即 x′_i = max_j(e_ij)。动态选择邻居可扩大感受野，在给定 k 值下增强局部特征表达，从而提升三维网格语义分割精度。三个 EdgeConv 模块的输出被拼接成高层特征向量，最终输出每个 CoGP 在 c 个语义标签上的分类分数。
  • 基于 K-D 树的小批量构造策略。在 CoGP 点云中每个点都代表一个网格面片，若像传统点云那样随机采样组批，会破坏面片覆盖的完整性。为此论文用 K-D 树按坐标快速查询每个 CoGP 的 K 个邻域来组建小批量，保证三维网格的语义分割结果完整，且规定一个 CoGP 只属于一个小批量。本文 K 取 800，邻居数 k 取 30，纹理采样点数取 243。
  • 系统化的超参数与配置消融设计。论文设计了四种特征配置（cf.1–cf.4）以分离纹理、空间信息与 TIF 模块的贡献，并对纹理采样点数（每边 3、5、7、9 个点，即每面片 27、75、147、243 个采样点）、小批量内 CoGP 数量（128、256、512、800）与 EdgeConv 邻居数（5、10、20、30）分别开展敏感性实验，为结构与参数选择提供依据。

实验与结果

实验使用语义城市网格基准数据集（SUM）：覆盖芬兰赫尔辛基约 4 km²，含地面、植被、建筑物、水体、汽车、船只 6 类；纹理网格由倾斜航空影像经 ContextCapture 生成，地面采样距离 7.5 cm。数据共 64 个区块，选取 12 个作训练集、12 个作验证集，面片总数 7 479 164 个（训练 3 787 315、验证 3 691 849）。类别分布极不均衡：地面（训练 17.17%、验证 17.02%）、植被（22.19%、23.57%）、建筑物（54.21%、56.63%）、水体（1.17%、0.31%）、汽车（2.95%、2.22%）、船只（2.32%、0.26%）。评价采用混淆矩阵导出的逐类精度、召回率、F1 与 IoU，以及全局的 OA、Kap、mP、mR、mF1、mIoU。

对比方法包括发布 SUM 数据集的 Gao 等的方法、Wilk 等的方法，以及 PointNet、RandLA-Net、SPG、PointNet++、KPConv 五种点云深度学习方法（对照方法的点云由网格采样并带颜色生成）。结果表明所提方法在所有指标上均优于其他方法：OA、Kap、mP、mR、mF1 与 mIoU 分别为 93.3%、88.7%、79.6%、83.0%、80.7% 和 69.6%。相较 Gao 等的方法，mAcc、mIoU 与 mF1 分别领先 12.4%、3.4% 与 6.9%；相较其余六种方法，mAcc 领先 7.9%–36.9%、mIoU 领先 0.6%–32.7%、mF1 领先 3.0%–36.1%，其中船只类 mIoU 提升 27.8%–43.5%，说明本方法在类别极不均衡条件下更具优势。逐类看，建筑物类最好，精度、召回率、F1 与 IoU 均超过 90%；汽车类最难，不同配置下 IoU 在 1% 至约 59% 之间波动，因其纹理与位置和地面相近而常被误判为地面。模型规模方面，SUM 方法的模型体积是本方法的 242.87 倍，说明简洁结构即可取得有竞争力的结果。

消融实验给出三方面结论：其一，TIF 模块有效——含 TIF 的 cf.1 在所有指标上优于不含 TIF 的 cf.4，尤以船只类显著，其精度、召回率、F1 与 IoU 分别提升 6.5%、12.9%、8.8% 与 8.5%。其二，原始纹理并非总是有益——cf.1 相比仅用空间信息的 cf.2 使 mIoU 提升 2.7%，而直接用原始纹理的 cf.4 相比 cf.2 反而使 mIoU 下降 2.2%，印证了含噪冗余纹理会带来负面影响，也反证了 TIF 模块的必要性。其三，空间信息更为关键——去掉空间信息后 mIoU 下降 30.1%，且 cf.2 的各项指标高于 cf.3，说明三维空间信息有助于区分纹理相似的地物（如地面与建筑屋顶）。超参数分析显示，纹理采样点数（27/75/147/243）、小批量内 CoGP 数（128/256/512/800）与 EdgeConv 邻居数（5/10/20/30）增加都能提升精度，但增益逐渐趋缓，最终折中取 243、800 与 30。

结论与意义

论文指出，尽管三维网格是摄影测量与遥感领域的最终用户产品之一，面向城市等复杂场景的语义三维网格分割研究仍处于起步阶段。本文提出的 mesh-based DGCNN 以简洁的网络结构解决了这一任务：先为每个面片构造包含 XYZ 坐标、RGB 信息与法向量的固有复合输入特征向量，再针对采样点 RGB 易受噪声影响、存在冗余的问题嵌入 TIF 模块以生成纹理高层语义特征。在 SUM 数据集六类语义分割任务上，该方法与当时最先进方法及多种点云深度学习方法相比取得领先精度，OA、Kap、mP、mR、mF1、mIoU 分别为 93.3%、88.7%、79.6%、83.0%、80.7% 与 69.6%，验证了“几何 + 纹理”复合特征建模的有效性。方法可服务于实景三维城市建设、城市规划与三维场景理解等应用。

论文也明确指出局限：各类别面片数量极不均衡，如船只类在训练与验证数据中仅占 2.32% 与 0.26%，这对语义分割是重大挑战，因此如何缓解类别不均衡被列为后续研究方向。

一句话总结

复合面片特征加纹理融合模块，城市纹理网格分割 OA 达 93.3%。
